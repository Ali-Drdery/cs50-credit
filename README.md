# CS50 Credit

This project was completed as part of Harvard CS50x.

## Description
A C program that validates credit card numbers using Luhn’s Algorithm.

The program determines whether a card number is valid and identifies the card type:
- AMEX
- MASTERCARD
- VISA

If the card is invalid, the program prints `INVALID`.

## Technologies Used
- C
- CS50 Library

## Concepts Learned
- Algorithms
- Loops
- Conditionals
- Number manipulation
- Problem Solving

## Algorithm Used
Luhn’s Algorithm for credit card validation.
